sleepwalk

github ↗

Zero-perceived-downtime rebalancing for Firecracker microVMs, in Rust.

It moves a running VM to another host by snapshotting it, streaming its memory across and lazily restoring it with userfaultfd, only once the workload is verified to be idle. No Firecracker fork, no kernel patches.

sentinel

The engines behind the virtual labs on projectlighthouse, which I wrote in Rust.

A Kubernetes-style reconciler provisions Firecracker microVMs and Docker containers for each lab session and cleans them up when they expire, a WebSocket-to-SSH proxy powers the in-browser terminal, and a sandboxed code runner checks the DSA labs.

devsweep

github ↗

Finds and cleans what's eating a developer's disk, in Rust: target/, node_modules, Docker images, old toolchains, local AI models and about 50 tool caches.

Git decides what's safe to remove, and each tool cleans its own mess with its own command, like cargo clean, asking first.
